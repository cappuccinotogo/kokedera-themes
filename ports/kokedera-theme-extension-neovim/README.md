# Kokedera for Neovim

Nine moss temple palettes for Neovim, Treesitter, LSP, completion and popular plugins.

Nine palettes inspired by forest greens, weathered stone, and warm lantern light. Seven dark variants and two light variants, matching the Kokedera themes for VS Code, JetBrains, and Zed.

## Installation

Requires Neovim 0.9 or newer and a true-color terminal. The theme lives in the `ports/kokedera-theme-extension-neovim` folder of [kokedera-themes](https://github.com/cappuccinotogo/kokedera-themes). Copy that folder to `stdpath('data')/site/pack/themes/start/kokedera`, or let your plugin manager clone the repository and add the folder to the runtime path. With lazy.nvim:

```lua
{
  'cappuccinotogo/kokedera-themes',
  lazy = false,
  priority = 1000,
  config = function(plugin)
    vim.opt.rtp:append(plugin.dir .. '/ports/kokedera-theme-extension-neovim')
    require('kokedera').setup({ variant = 'dusk' })
    vim.cmd.colorscheme('kokedera')
  end,
}
```

Without a plugin manager, add to `init.lua`:

```lua
require('kokedera').setup({ variant = 'dusk' })
vim.cmd.colorscheme('kokedera')
```

Choose any of `dusk`, `morning`, `night`, `spring`, `summer`, `autumn`, `winter`, `rain`, `mist`. Switch at runtime with `:colorscheme kokedera-morning`. The setup call configures the theme; the colorscheme command applies it. Optional setup keys: `transparent = true`, `terminal_colors = false`, and `overrides = { Comment = { fg = '#94aa87', italic = false } }`.

For lualine, use `options = { theme = 'kokedera' }` after loading the colorscheme. The theme includes core UI, diagnostics, Treesitter/LSP, Telescope, nvim-tree, Neo-tree, gitsigns, WhichKey, Lazy, Mason, nvim-cmp and blink.cmp highlights. Plugins are optional and are not installed by this package.

## Consistency and maintenance

This folder contains ready-to-use files generated by [kokedera-themes](https://github.com/cappuccinotogo/kokedera-themes). Please open issues and pull requests there. The same palette snapshot supplies every port; terminal ANSI colors and syntax roles come from the existing VS Code themes. Application-specific UI roles are mapped in the central generators.

To change colors or fix a mapping, edit the central source in [kokedera-themes](https://github.com/cappuccinotogo/kokedera-themes) and regenerate. Avoid hand-editing generated files here. `kokedera.json` records the palette and generator hashes, all nine variants, and file checksums. Run `python scripts/verify.py` to check this checkout.

These are direct-install ports. A GitHub release does not imply approval or inclusion in an application's theme store. See the installation notes for application-specific limits.
