# Kokedera for Command-Line Tools

Matching themes for Starship, tmux, Zellij, lazygit, fzf, btop, Yazi, and bat.

Nine palettes inspired by forest greens, weathered stone, and warm lantern light. Seven dark variants and two light variants, matching the Kokedera themes for VS Code, JetBrains, and Zed.

[Explore Kokedera](https://kokedera.style) · [All ports](https://github.com/cappuccinotogo/kokedera-themes)

## Installation

Download this folder, or the `kokedera-all-ports` archive from the latest release of kokedera-themes. Every tool has nine variants; the examples select Dusk. Use the matching terminal palette from [Kokedera for Terminals](https://github.com/cappuccinotogo/kokedera-themes/tree/main/ports/kokedera-theme-terminals) for application areas that inherit terminal colors. These files only style the named tools; they do not install or reconfigure your shell.

### Starship

Each `starship/kokedera-<variant>.toml` is a complete minimal prompt, with a named palette and styles that actually use it. Try one by pointing `STARSHIP_CONFIG` at its absolute path before starting a shell with Starship initialized. To preserve your existing prompt, merge its `[palettes.kokedera_dusk]` table, select `palette = "kokedera_dusk"` at the top level, and apply the supplied module styles individually.

### tmux

Add `source-file "/absolute/path/to/tmux/kokedera-dusk.conf"` at the end of your `~/.tmux.conf`, then reload that file. The theme changes colors only and preserves your status-line content and key bindings. A true-color terminal is recommended.

### Zellij

Copy the KDL files into `~/.config/zellij/themes/` (or your configured theme directory), then set `theme "kokedera-dusk"` in `config.kdl`. Uses the current component-based theme format. Each variant sets its own background.

### lazygit

Merge the `gui.theme` mapping from `lazygit/kokedera-dusk.yml` into your existing configuration. Do not replace the entire config. To find the directory run `lazygit --print-config-dir`; open its `config.yml`. Reopen lazygit after editing. Its base background comes from the terminal.

### fzf

Source the variant matching your shell from the `fzf/` folder: `.sh` for POSIX shells/Bash/Zsh, `.fish` for Fish, or dot-source `.ps1` for PowerShell. The snippets preserve existing `FZF_DEFAULT_OPTS` and append Kokedera's color option. Add the source command to your shell profile for persistence. Source only one variant per shell startup.

### btop

Copy the `.theme` files to `~/.config/btop/themes/` (respecting `XDG_CONFIG_HOME` if set). Select `kokedera-dusk` in btop's Options → Color theme, and enable Theme background to use its background color.

### Yazi

Copy the nine `yazi/kokedera-*.yazi` directories into `~/.config/yazi/flavors/` (Windows: `%APPDATA%\yazi\config\flavors\`). Merge the supplied `yazi/theme.toml` flavor selection into your own `theme.toml`. The example automatically uses Dusk for dark terminals and Morning for light terminals. Set both `dark` and `light` to the same flavor to force it. Restart Yazi. Includes a matching TextMate syntax theme for file previews. Targets the current schema with `mgr` and `indicator` sections.

### bat

Run `bat --config-dir` to find your configuration directory. Copy the `bat/*.tmTheme` files into its `themes/` subdirectory, then run `bat cache --build`. Select with `bat --theme="Kokedera Dusk" demo/example.py`, set `BAT_THEME`, or add `--theme="Kokedera Dusk"` to bat's config file.

## Consistency and maintenance

This folder contains ready-to-use files generated by [kokedera-themes](https://github.com/cappuccinotogo/kokedera-themes). Please open issues and pull requests there. The same palette snapshot supplies every port; terminal ANSI colors and syntax roles come from the existing VS Code themes. Application-specific UI roles are mapped in the central generators.

To change colors or fix a mapping, edit the central source in [kokedera-themes](https://github.com/cappuccinotogo/kokedera-themes) and regenerate. Avoid hand-editing generated files here. `kokedera.json` records the palette and generator hashes, all nine variants, and file checksums. Run `python scripts/verify.py` to check this checkout.

These are direct-install ports. A GitHub release does not imply approval or inclusion in an application's theme store. See the installation notes for application-specific limits.
