# Kokedera for JupyterLab

A prebuilt JupyterLab 4 extension registering all nine Kokedera light and dark themes.

Nine palettes inspired by forest greens, weathered stone, and warm lantern light. Seven dark variants and two light variants, matching the Kokedera themes for VS Code, JetBrains, and Zed.

[Explore Kokedera](https://kokedera.style) · [All ports](https://github.com/cappuccinotogo/kokedera-themes)

## Installation

Requires Python 3.10+ and JupyterLab 4 with its standard JupyterLab Light and Dark theme packages.

Build a wheel from this repository with Node.js 22+ installed:

```sh
python -m venv .venv
# Activate .venv for your platform.
python -m pip install "jupyterlab>=4,<5" "jupyter-builder>=1.2,<2" build
npm install
npm run build
npm test
python -m build --wheel
```

Install the generated wheel into the environment running JupyterLab with `python -m pip install dist/kokedera_jupyterlab-1.0.0-py3-none-any.whl`, restart JupyterLab, then choose **Settings → Theme → Kokedera <variant>**. Installing a prebuilt wheel requires no Node.js and no `jupyter lab build`.

The nine registered themes declare their light/dark mode. Each loads the matching built-in JupyterLab foundation followed by Kokedera’s interface, notebook and syntax colors. Set the terminal theme to `inherit` to reuse the surrounding foreground/background; JupyterLab keeps its own terminal ANSI palette. This keeps native fonts and layout consistent as JupyterLab evolves. Remove with `python -m pip uninstall kokedera-jupyterlab`. A repository checkout is source; a successful build produces the prebuilt extension and wheel.

## Consistency and maintenance

This folder contains ready-to-use files generated by [kokedera-themes](https://github.com/cappuccinotogo/kokedera-themes). Please open issues and pull requests there. The same palette snapshot supplies every port; terminal ANSI colors and syntax roles come from the existing VS Code themes. Application-specific UI roles are mapped in the central generators.

To change colors or fix a mapping, edit the central source in [kokedera-themes](https://github.com/cappuccinotogo/kokedera-themes) and regenerate. Avoid hand-editing generated files here. `kokedera.json` records the palette and generator hashes, all nine variants, and file checksums. Run `python scripts/verify.py` to check this checkout.

These are direct-install ports. A GitHub release does not imply approval or inclusion in an application's theme store. See the installation notes for application-specific limits.
